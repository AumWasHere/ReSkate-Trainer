# Trainer

A custom physics trainer preset for ReSkate and clone my style at **Skater XL**.

## Active Modes
- **Hardcore**
- **Realistic**

## Features

### Physics Tweaks
- Tuned jump heights (base, min, max)
- Custom sprint speed and boost
- Adjusted grind friction and lock distance
- Modified spin speed and body spin timing
- Wipeout thresholds fine-tuned for realistic falls


## Installation
1. Place the `trainer.json` file `%localappdata%\ReSkate` then move or copy `trainer.json` into **"trainer"** folder.
2. **Don't forget to backup** your file or rename your original file `trainer.json.bak`
3. Launch the game and load the preset from the trainer menu.

## Notes
- All frozen values are locked and will not be overridden by in-game settings.
- Compatible with Skate version 2.1.2 and above.
